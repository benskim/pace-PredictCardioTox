# QTc Measurement Confidence Engine

Version: 3.0

Status: Production Source of Truth

---

# 1. Purpose

This document defines the canonical schema, artifact interfaces, identifiers, aggregation rules, targets, and reproducibility requirements used throughout the QTc Measurement Confidence Engine project.

This document is the single source of truth for:

* schemas
* column names
* artifact names
* primary keys
* granularity definitions
* aggregation rules

All notebooks (01–11) must comply.

No notebook may redefine:

* identifiers
* column names
* units
* artifacts
* primary keys
* target definitions

---

# 2. Naming Convention

Mandatory Rule:

All schema fields, identifiers, artifact columns, and features must use:

lower_snake_case

Examples:

```text
record_id
lead_id
beat_id

lead_agreement_score
qt_variance_leads

t_end_uncertainty_ms
signal_quality_score
```

Capitalized names may be used only in documentation prose.

They are not valid schema names.

---

# 3. Core Design Principle

This project does NOT build a QT measurement algorithm.

This project builds a QT Measurement Confidence Engine.

Every retained feature must contribute to:

* Signal Quality Evidence
* Delineation Evidence
* Morphology Evidence
* Measurement Agreement Evidence
* Clinical Context Evidence

Features that cannot support confidence estimation should be excluded.

---

# 4. Canonical Hierarchy

All datasets follow:

```text
dataset
 → record
    → lead
       → beat
```

No notebook may violate this hierarchy.
