# CONFIDENCE_MODEL_SPEC.md

# QTc Measurement Confidence Engine

Version: 1.0

Status: Production Specification

---

# 1. Purpose

This specification defines the requirements for Notebook 10:

```text
10_confidence_model.ipynb
```

The objective is to estimate:

```text
P(QT measurement is trustworthy)
```

using evidence assembled in:

```text
confidence_features.parquet
```

---

# 2. Input

Mandatory Input:

```text
confidence_features.parquet
```

Generated by:

```text
09_confidence_features.ipynb
```

Granularity:

```text
record_id
```

---

# 3. Evidence Domains

The model must consume features originating from:

1. Signal Quality Evidence
2. Delineation Evidence
3. Morphology Evidence
4. Measurement Reliability Evidence
5. Clinical Context Evidence

No evidence domain may be excluded without justification.

---

# 4. Phase 1 Targets

Available datasets:

```text
PTBXL
LUDB
NSTDB
```

Pseudo-targets:

```text
lead_agreement_score

beat_agreement_score

repeatability_score

internal_consistency_score
```

Target construction must be documented.

---

# 5. Forbidden Targets

The following are unavailable in Phase 1:

```text
absolute_qt_error_ms

expert_disagreement_ms

true_t_end_error_ms

cross_lead_disagreement_ms
```

These belong to Phase 3 after QTDB integration.

---

# 6. Model Candidates

Mandatory baseline models:

```text
Random Forest

XGBoost

LightGBM
```

Optional:

```text
CatBoost
```

---

# 7. Training Strategy

Requirements:

```text
5-fold cross validation
```

and

```text
Leave-One-Dataset-Out validation
```

must both be performed.

Example:

Train:
PTBXL + LUDB

Test:
NSTDB

````

Repeat for all datasets.

---

# 8. Calibration

Confidence outputs must be calibrated.

Allowed methods:

```text
Platt Scaling

Isotonic Regression
````

Uncalibrated probabilities may not be deployed.

---

# 9. Evaluation Metrics

Mandatory:

```text
ROC-AUC

PR-AUC

Brier Score

Calibration Error (ECE)
```

Calibration plots must be generated.

---

# 10. Explainability

Mandatory:

```text
SHAP
```

Generate:

* global importance
* local explanations

Top 20 features must be reported.

---

# 11. Output

Primary output:

```text
confidence_probability
```

Range:

```text
0.0 – 1.0
```

Interpretation:

Probability that the QT/QTc measurement is reliable.

---

# 12. Export

Artifact:

```text
confidence_predictions.parquet
```

Required columns:

```text
record_id

confidence_probability

model_name

calibration_method

pipeline_version
```

---

# 13. Leakage Prevention

Forbidden features:

```text
absolute_qt_error_ms

expert_disagreement_ms

true_t_end_error_ms

confidence_label
```

Use of these variables invalidates evaluation.

---

# 14. Deliverables

Notebook must generate:

* performance table
* ROC curve
* PR curve
* calibration curve
* SHAP summary
* feature ranking
* exported predictions
