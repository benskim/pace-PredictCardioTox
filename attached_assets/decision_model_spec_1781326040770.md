# DECISION_MODEL_SPEC.md

# QTc Measurement Confidence Engine

Version: 1.0

Status: Production Specification

---

# 1. Purpose

This specification defines Notebook 11:

```text
11_decision_model.ipynb
```

The notebook converts:

```text
confidence_probability
```

into operational decisions.

---

# 2. Input

Mandatory Input:

```text
confidence_predictions.parquet
```

Generated by:

```text
10_confidence_model.ipynb
```

---

# 3. Decision Philosophy

Confidence is continuous.

Operational workflows require discrete actions.

The Decision Model maps probability to actions.

---

# 4. Allowed Decisions

Exactly three classes:

```text
ACCEPT

REVIEW

REJECT
```

Definitions:

ACCEPT
→ trusted measurement

REVIEW
→ manual verification recommended

REJECT
→ measurement unsuitable for use

---

# 5. Threshold Selection

Thresholds must be derived empirically.

Forbidden:

```text
0.5

0.7

0.9
```

or any hardcoded values.

Thresholds must be optimized using validation data.

---

# 6. Optimization Objectives

The decision system must jointly optimize:

```text
coverage

error_capture_rate

review_rate
```

Definitions:

Coverage
= ACCEPT proportion

Review Rate
= REVIEW proportion

Error Capture Rate
= fraction of unreliable measurements intercepted

---

# 7. Safety Requirement

Primary objective:

```text
Minimize false ACCEPT decisions.
```

Clinical safety has priority over coverage.

---

# 8. Evaluation Metrics

Mandatory:

```text
Coverage

Review Rate

Reject Rate

False Accept Rate

False Reject Rate

Error Capture Rate
```

---

# 9. Sensitivity Analysis

Evaluate multiple threshold pairs.

Example:

```text
T_low

T_high
```

Generate performance surfaces.

Do not report a single threshold only.

---

# 10. Reliability Analysis

Compare:

```text
ACCEPT group

REVIEW group

REJECT group
```

for:

* signal quality
* morphology ambiguity
* agreement metrics

Expected ordering:

```text
ACCEPT > REVIEW > REJECT
```

for confidence.

---

# 11. Output

Artifact:

```text
decision_results.parquet
```

Required columns:

```text
record_id

confidence_probability

decision_class

pipeline_version
```

---

# 12. Clinical Readiness Report

Generate:

* confusion matrix
* decision distribution
* safety analysis
* threshold rationale
* deployment recommendation

---

# 13. Deployment Rule

Deployment thresholds must originate from:

```text
11_decision_model.ipynb
```

No thresholds may be defined in:

```text
10_confidence_model.ipynb
```

Modeling and decision policy must remain separated.
